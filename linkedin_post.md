## 🤖 How the Agent Works

The agent follows a sophisticated workflow:
1. **User Query** → Received by the assistant node
2. **Decision Making** → LLM decides if tools are needed
3. **Tool Execution** → Web search or Wikipedia search if required
4. **Response Generation** → LLM synthesizes information with sources
5. **Memory Update** → Conversation state saved for context

The graph-based architecture allows for flexible agent behavior with conditional tool usage based on query complexity.
